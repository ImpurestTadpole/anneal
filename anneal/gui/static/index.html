    How to write an import file

    One row per material. A header row names the columns. Anneal recognises common datasheet names and units, and converts them: GPa, MPa, psi, ksi; g/cm³, kg/m³, lb/in³; mm, in. Write the unit in the header, as E (GPa), or in the cell, as 3.8 GPa. Commas, semicolons and tabs all work, and so do decimal commas.

    name,E (GPa),Poisson,density (g/cm3),yield (MPa),Z strength (MPa),process,min wall (mm),note
PETG-CF Bambu,3.8,0.35,1.25,52,30,FDM,0.8,Bambu Lab TDS 2024
Inconel 718,200,0.29,8.19,1034,,LPBF,0.4,

    Needed: name, E, Poisson's ratio, density, yield (or tensile strength). Optional: Z (layer) strength, which becomes the layer-strength factor; process (FDM, FFF, SLS, MJF, LPBF, SLM, DMLS or one of yours); minimum wall; note. JSON works too: {"materials": {"Name": {"E": "3.8 GPa", "nu": 0.35, …}}}, which is also what Export my library writes.
